# Student Expense Tracker

A simple Python command-line app for tracking student expenses.

## Features
- Add an expense with category, description and amount
- View recorded expenses
- Calculate total spending
- Store records locally in `expenses.csv`

## Run
Requires Python 3.8+.

```bash
python main.py
```

The CSV file is created automatically in the folder when you first add an expense.

## Project files
- `main.py`: application code
- `expenses.csv`: data file generated when the program runs
